# du-template-analytics

PoC template · **Analytics project (Cookiecutter Data Science)**.

A full CCDS project — data/ hierarchy, a reusable analysis package, and an exploratory notebook.

Follows [cookiecutter-data-science](https://github.com/drivendataorg/cookiecutter-data-science). Used by the digitalization
portal's PoC builder via GitHub "generate from template" — the portal creates a
use-case repository from this template, then overlays the case's own files.

Run locally: `jupyter lab notebooks/` (from `poc/`).
